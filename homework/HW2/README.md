1. $T(n) = T(n-1) + 8, \quad T(1) = 1$展開推導：$$T(n) = T(n-2) + 8 + 8 = T(n-2) + 2 \times 8$$依此類推，展開 $k$ 次後：$$T(n) = T(n-k) + k \times 8$$當 $n-k = 1$（即 $k = n-1$）時：$$T(n) = T(1) + (n-1) \times 8 = 1 + 8n - 8 = 8n - 7$$精確解：$T(n) = 8n - 7$Big O 複雜度：$O(n)$（線性時間）2. $T(n) = 2T(n-1) + 9, \quad T(1) = 1$展開推導：$$T(n) = 2[2T(n-2) + 9] + 9 = 4T(n-2) + 2 \times 9 + 9$$展開 $k$ 次後：$$T(n) = 2^k T(n-k) + 9 \sum_{i=0}^{k-1} 2^i$$當 $n-k = 1$（即 $k = n-1$）時：$$T(n) = 2^{n-1} T(1) + 9(2^{n-1} - 1) = 2^{n-1} + 9 \cdot 2^{n-1} - 9 = 10 \cdot 2^{n-1} - 9$$精確解：$T(n) = 10 \cdot 2^{n-1} - 9$Big O 複雜度：$O(2^n)$（指數時間）3. $T(n) = 2T(n/2) + 1, \quad T(1) = 1$主定理（Master Theorem）分析：此為典型分治法結構（$a=2, b=2, f(n)=1$）。計算 $n^{\log_b a} = n^{\log_2 2} = n^1 = n$。因為 $f(n) = O(n^0)$小於 $n^1$，符合主定理第一種情況。精確解（假設 $n = 2^k$）：$$T(n) = 2n - 1$$Big O 複雜度：$O(n)$（線性時間，例如歸併排序的時間複雜度規律）4. $T(n) = T(n/2) + 1, \quad T(1) = 1$主定理（Master Theorem）分析：此為二分搜尋法結構（$a=1, b=2, f(n)=1$）。計算 $n^{\log_b a} = n^{\log_2 1} = n^0 = 1$。因為 $f(n) = \Theta(n^0 \log^0 n) = \Theta(1)$，符合主定理第二種情況。精確解（假設 $n = 2^k$）：$$T(n) = \log_2 n + 1$$Big O 複雜度：$O(\log n)$（對數時間）總結比較表編號遞迴方程式精確解 (Closed-form)Big O 複雜度1$T(n) = T(n-1) + 8$$8n - 7$$O(n)$2$T(n) = 2T(n-1) + 9$$10 \cdot 2^{n-1} - 9$$O(2^n)$3$T(n) = 2T(n/2) + 1$$2n - 1$$O(n)$4$T(n) = T(n/2) + 1$$\log_2 n + 1$$O(\log n)$
